# Documentação da Pasta: aula107-funcoes-uteis-zip-count-groupby-filter-functools-map-etc

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python:

1. **aula107-exercicio-unindo-listas-func-zip.py**: 
   - Exercício prático para unir listas utilizando a função `zip`.
   - Recursos abordados:
     - Função `zip`.
     - List comprehension.

2. **aula108-count-iterador-sem-fim.py**: 
   - Demonstra o uso da função `count` do módulo `itertools` para criar iteradores infinitos.

3. **aula109-permutacao-e-combinacao.py**: 
   - Explora as funções `permutations` e `combinations` do módulo `itertools` para gerar permutações e combinações de elementos.

4. **aula110-groupby-agrupamento.py**: 
   - Mostra como utilizar a função `groupby` do módulo `itertools` para agrupar dados.

5. **aula111-map-partial-generator-type.py**: 
   - Explica o uso das funções `map` e `partial`, além de conceitos de geradores e tipos de dados.

6. **aula112-filter-filtro-funcional.py**: 
   - Demonstra o uso da função `filter` para criar filtros funcionais em coleções de dados.

7. **aula113-modulo-functools-reduce.py**: 
   - Introduz a função `reduce` do módulo `functools` para realizar operações cumulativas em coleções.

8. **aula114-recursividade-na-funcao.py**: 
   - Explica o conceito de recursividade em funções e apresenta exemplos práticos.

## Recursos Abordados

- Função `zip` para unir listas.
- Função `count` do módulo `itertools` para iteradores infinitos.
- Funções `permutations` e `combinations` do módulo `itertools`.
- Função `groupby` para agrupamento de dados.
- Funções `map` e `partial`.
- Função `filter` para filtros funcionais.
- Função `reduce` do módulo `functools`.
- Recursividade em funções.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.

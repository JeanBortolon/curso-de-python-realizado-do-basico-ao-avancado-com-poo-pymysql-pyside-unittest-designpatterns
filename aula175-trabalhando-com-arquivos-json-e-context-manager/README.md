# Documentação da Pasta: aula175-trabalhando-com-arquivos-json-e-context-manager

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python e JSON:

1. **aula116-context-manager-manipulando-arquivos.py**: 
   - Demonstra o uso de context managers (`with open`) para manipulação de arquivos.
   - Recursos abordados:
     - Modos de abertura de arquivos (`r`, `w`, `a`, etc.).
     - Métodos úteis como `write`, `read`, `writelines`, `readline` e `readlines`.
     - Uso do módulo `os` para operações como renomear e apagar arquivos.

2. **aula117-salvando-dados-em-json.py**: 
   - Mostra como salvar e carregar dados em arquivos JSON utilizando o módulo `json`.
   - Recursos abordados:
     - Funções `json.dump` e `json.load`.
     - Configurações como `ensure_ascii` e `indent` para formatação de JSON.

3. **aula118-problema-em-params-mutaveis.py**: 
   - Explora problemas relacionados ao uso de parâmetros mutáveis em funções.

4. **aula119-2-exercicio-json-reduzindo-os-if's.py**: 
   - Exercício prático para trabalhar com JSON e reduzir o uso de condicionais.

5. **aula119-exercicio-com-json.py**: 
   - Outro exercício prático envolvendo manipulação de arquivos JSON.

6. **aula119-lista-de-tarefas.py**: 
   - Implementa uma lista de tarefas utilizando arquivos JSON para persistência de dados.

7. **aula175.py**: 
   - Arquivo principal para consolidar os conceitos de manipulação de arquivos e JSON.

8. **aula176_dumps_e_loads_strings.py**: 
   - Demonstra o uso das funções `json.dumps` e `json.loads` para trabalhar com strings JSON.

9. **aula177_dump_e_load_arquivos.py**: 
   - Mostra como utilizar `json.dump` e `json.load` para salvar e carregar dados em arquivos JSON.

10. **aula116.txt, aula117.json, aula119.json, aula175.json**: 
    - Arquivos de exemplo gerados pelos scripts para armazenar dados persistentes.

11. **PathLib_obtendo_caminhos.jpg**: 
    - Imagem ilustrativa sobre o uso do módulo `PathLib` para manipulação de caminhos.

## Recursos Abordados

- Manipulação de arquivos com context managers (`with open`).
- Operações com arquivos JSON utilizando o módulo `json`.
- Persistência de dados em arquivos.
- Boas práticas para manipulação de arquivos e tratamento de erros.
- Uso do módulo `os` para operações no sistema de arquivos.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.

# Documentação da Pasta: aula101-variaveis-non-locals-adiamento-de-funcoes-decoradoras-e-conceitos

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python:

1. **aula101-adiamento-de-execucao-de-funcs.py**: 
   - Demonstra o conceito de adiamento da execução de funções utilizando funções internas e parâmetros pré-definidos.
   - Recursos abordados:
     - Funções internas (closures).
     - Passagem de funções como argumentos.
     - Retorno de funções.

2. **aula102-variaveis-livres-non-locals.py**: 
   - Explora o uso de variáveis livres e a palavra-chave `nonlocal` em Python.

3. **aula103-funcoes-decoradoras.py**: 
   - Introduz o conceito de funções decoradoras e como elas podem ser usadas para modificar o comportamento de outras funções.

4. **aula104-decoradoras-syntax-sugar.py**: 
   - Explica o "syntax sugar" para decoradores, facilitando sua aplicação.

5. **aula105-decoradoras-com-parametro.py**: 
   - Mostra como criar decoradores que aceitam parâmetros.

6. **aula106-ordem-de-func-decoradoras.py**: 
   - Discute a ordem de execução de múltiplos decoradores aplicados a uma mesma função.

7. **parseando-playload-mqtt-medidor-khomp.py**: 
   - Um exemplo prático de parsing de payloads MQTT para medidores Khomp.

## Recursos Abordados

- Funções internas e closures.
- Uso de `nonlocal` para manipulação de variáveis livres.
- Criação e aplicação de decoradores.
- Decoradores com parâmetros.
- Ordem de execução de decoradores.
- Parsing de dados em payloads MQTT.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.

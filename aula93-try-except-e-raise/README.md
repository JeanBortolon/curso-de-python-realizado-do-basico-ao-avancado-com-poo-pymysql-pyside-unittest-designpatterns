# Documentação da Pasta: aula93-try-except-e-raise

## Conteúdo da Pasta
Esta pasta contém scripts Python que abordam os seguintes tópicos:

1. **Bloco `try` e `except`**:
   - `aula93-try-except-1.py`: Introdução ao uso do bloco `try` e `except` para tratamento de exceções em Python.

2. **Bloco `try` e `finally`**:
   - `aula94-try-finally.py`: Uso do bloco `finally` para executar código independentemente de exceções.

3. **Levantar Exceções com `raise`**:
   - `aula95-raise-levantando-exceções.py`: Como levantar exceções personalizadas utilizando a palavra-chave `raise`.

## Objetivo
Esta pasta serve como material de estudo para compreender e praticar conceitos fundamentais de tratamento de exceções em Python. Os exemplos fornecidos ajudam a entender como lidar com erros de forma segura e como criar exceções personalizadas para atender a necessidades específicas.

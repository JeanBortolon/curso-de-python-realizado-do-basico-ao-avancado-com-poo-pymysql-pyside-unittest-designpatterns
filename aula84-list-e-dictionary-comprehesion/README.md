# Documentação da Pasta: aula84-list-e-dictionary-comprehesion

## Conteúdo da Pasta
Esta pasta contém scripts Python que abordam os seguintes tópicos:

1. **List Comprehension**:
   - `aula84-list-comprehesion.py`: Introdução ao conceito de `list comprehension` e seus usos básicos para criar listas de forma mais eficiente e legível.
   - `aula85-list-comprehesion-com-mais-de-1-for.py`: Exemplos de `list comprehension` utilizando mais de um laço `for`.

2. **Dictionary e Set Comprehension**:
   - `aula86-dictionary-e-set-comprehension.py`: Introdução ao uso de `dictionary comprehension` e `set comprehension` para criar dicionários e conjuntos de forma eficiente.

## Objetivo
Esta pasta serve como material de estudo para compreender e praticar os conceitos de `list comprehension`, `dictionary comprehension` e `set comprehension` em Python. Os exemplos e exercícios fornecidos ajudam a reforçar o aprendizado e a aplicar esses conceitos em situações práticas.

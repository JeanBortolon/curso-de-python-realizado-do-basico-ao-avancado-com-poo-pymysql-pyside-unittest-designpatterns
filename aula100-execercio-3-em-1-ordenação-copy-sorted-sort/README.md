# Aula 100 - Exercício 3 em 1: Ordenação com Copy, Sorted e Sort

## Conteúdo da Pasta
Esta pasta contém exercícios e exemplos práticos relacionados aos conceitos de ordenação em Python. Os programas aqui desenvolvidos abordam diferentes formas de ordenar listas e outros iteráveis, utilizando as funções e métodos nativos do Python.

## Recursos Abordados

1. **Função `sorted`**:
   - Ordenação de iteráveis de forma estável e retornando uma nova lista.
   - Uso de parâmetros como `key` e `reverse` para personalizar a ordenação.

2. **Método `sort`**:
   - Ordenação in-place de listas.
   - Diferenças entre `sort` e `sorted`.

3. **Cópia de listas (`copy`)**:
   - Criação de cópias rasas e profundas de listas para preservar os dados originais durante a ordenação.

4. **Ordenação personalizada**:
   - Uso de funções lambda e outras funções como `itemgetter` para ordenar com base em critérios específicos.

5. **Comparação de desempenho**:
   - Discussão sobre eficiência e casos de uso para `sorted` e `sort`.

## Objetivo
O objetivo desta aula é consolidar o entendimento sobre as diferentes formas de ordenar dados em Python, destacando as vantagens e desvantagens de cada abordagem. Além disso, os exercícios ajudam a praticar a manipulação de listas e iteráveis, bem como o uso de funções auxiliares para personalizar a ordenação.

# Aula 201 - PySide6: Interface Gráfica do Usuário (GUI)

Este diretório contém exemplos e exercícios relacionados ao uso do PySide6 para criar interfaces gráficas do usuário (GUIs) em Python. Abaixo está uma descrição dos arquivos presentes e os recursos abordados em cada um deles:

## Conteúdo

### 1. instalando-e-testando-pyside6-gui.py
- **Descrição:** Demonstra como instalar o PySide6 e criar uma aplicação GUI básica para testar a instalação.
- **Recursos abordados:**
  - Instalação do PySide6.
  - Criação de uma aplicação GUI simples.

### 2. Qapplication-e-Qpushbutton.py
- **Descrição:** Introdução ao uso de `QApplication` e `QPushButton` para criar e exibir botões em uma aplicação GUI.
- **Recursos abordados:**
  - Configuração de uma aplicação com `QApplication`.
  - Criação e manipulação de botões com `QPushButton`.

### 3. Qmainwindow-e-centralwidget.py
- **Descrição:** Explora o uso de `QMainWindow` e `QWidget` como widgets centrais para estruturar uma aplicação GUI.
- **Recursos abordados:**
  - Estruturação de janelas principais com `QMainWindow`.
  - Definição de widgets centrais com `QWidget`.

### 4. signal-e-slot.py
- **Descrição:** Explica o conceito de sinais e slots no PySide6 para comunicação entre componentes da GUI.
- **Recursos abordados:**
  - Uso de sinais e slots para interação entre widgets.
  - Conexão de eventos a funções específicas.

### 5. classes-e-heranças-no-pyside.py
- **Descrição:** Mostra como organizar o código usando classes e herança para criar GUIs mais complexas e reutilizáveis.
- **Recursos abordados:**
  - Organização de código com classes.
  - Uso de herança para estender funcionalidades de widgets.

---

## Observações
- Certifique-se de ter o PySide6 instalado antes de executar os exemplos.
- Consulte a [documentação oficial do PySide6](https://doc.qt.io/qtforpython/) para mais detalhes e recursos adicionais.

# Documentação da Pasta: aula178-arquivos-csv

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python e CSV:

1. **aula178_CSV.py**: 
   - Introduz o formato CSV (Comma Separated Values) e suas características.
   - Recursos abordados:
     - Estrutura básica de arquivos CSV.
     - Regras para criação e manipulação de arquivos CSV.

2. **aula179_csv.reader_csv.DictReader.py**: 
   - Demonstra como ler arquivos CSV utilizando as funções `csv.reader` e `csv.DictReader`.
   - Recursos abordados:
     - Leitura de arquivos CSV como listas com `csv.reader`.
     - Leitura de arquivos CSV como dicionários com `csv.DictReader`.

3. **aula180_csv.writer_e_csv.DictWriter.py**: 
   - Mostra como escrever em arquivos CSV utilizando as funções `csv.writer` e `csv.DictWriter`.
   - Recursos abordados:
     - Escrita de arquivos CSV como listas com `csv.writer`.
     - Escrita de arquivos CSV como dicionários com `csv.DictWriter`.

4. **aula178-ex.csv, aula178-gs.csv, aula179.csv, aula180.csv**: 
   - Arquivos de exemplo utilizados para leitura e escrita nos scripts.

## Recursos Abordados

- Manipulação de arquivos CSV com o módulo `csv`.
- Leitura de arquivos CSV como listas e dicionários.
- Escrita de arquivos CSV com listas e dicionários.
- Boas práticas para manipulação de arquivos CSV.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.

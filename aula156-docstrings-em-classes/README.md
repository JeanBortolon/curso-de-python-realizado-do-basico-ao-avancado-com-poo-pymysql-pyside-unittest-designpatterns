# Documentação da Pasta: aula156-docstrings-em-classes

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python:

1. **aula156-docstrings-em-classes.py**: 
   - Apresenta exemplos de uso de docstrings em funções e classes.
   - Recursos abordados:
     - Docstrings para documentação de funções.
     - Tipagem de parâmetros e retorno.
     - Exemplos práticos de funções como `soma` e `multiplica` com explicações detalhadas.

2. **main.py**: 
   - Demonstra como importar e utilizar módulos com docstrings.
   - Recursos abordados:
     - Uso de `help()` para visualizar docstrings.
     - Importação de módulos e exploração de seus atributos.

3. **varias_linhas.py**: 
   - Contém um exemplo de docstring de múltiplas linhas para descrever o propósito do módulo.
   - Recursos abordados:
     - Docstrings de múltiplas linhas para módulos.
     - Estrutura e boas práticas para documentação de código.

## Recursos Abordados

- Docstrings para funções, classes e módulos.
- Tipagem de parâmetros e retorno em funções.
- Uso de `help()` para explorar documentação.
- Boas práticas para escrever docstrings detalhadas e informativas.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.

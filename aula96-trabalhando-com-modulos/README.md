# Documentação da Pasta: aula96-trabalhando-com-modulos

## Conteúdo da Pasta
Esta pasta contém scripts Python que abordam os seguintes tópicos:

1. **Módulos e Importação**:
   - `aula96-modulos-e-import.py`: Introdução ao uso de módulos e à importação de funções e variáveis em Python.

2. **Modularização**:
   - `aula97-modularização.py`: Conceitos de modularização para organizar melhor o código em diferentes arquivos.
   - `aula97-modulo-da-aula-97.py`: Exemplo de módulo criado para ser utilizado no script principal.

3. **Recarregando Módulos**:
   - `aula98-funcao-reload-recarregando-modulos.py`: Uso da função `reload` para recarregar módulos durante a execução do programa.
   - `aula98-modulo-recarregavel-da-reload.py`: Exemplo de módulo utilizado para demonstrar a recarga com `reload`.

4. **Módulos e Pacotes**:
   - `aula99-modulos-e-packages.py`: Introdução ao conceito de pacotes em Python e como utilizá-los para organizar módulos.

## Objetivo
Esta pasta serve como material de estudo para compreender e praticar conceitos fundamentais sobre módulos e pacotes em Python. Os exemplos fornecidos ajudam a entender como organizar o código de forma eficiente, reutilizar funcionalidades e trabalhar com recarga de módulos durante o desenvolvimento.

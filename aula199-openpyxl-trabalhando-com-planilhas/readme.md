# Aula 199 - Trabalhando com Planilhas (OpenPyXL)

## Descrição
Esta pasta contém os arquivos e exemplos relacionados ao uso da biblioteca **OpenPyXL** para manipulação de planilhas no formato Excel (.xlsx). A aula aborda conceitos e práticas fundamentais para trabalhar com planilhas de forma programática utilizando Python.

## Conteúdo Abordado

1. **Introdução ao OpenPyXL**
   - O que é a biblioteca OpenPyXL e suas principais funcionalidades.
   - Como instalar a biblioteca.

2. **Criação de Planilhas**
   - Criar novas planilhas do zero.
   - Adicionar dados em células específicas.

3. **Leitura de Planilhas**
   - Abrir arquivos existentes no formato .xlsx.
   - Ler dados de células específicas.
   - Iterar sobre linhas e colunas.

4. **Edição de Planilhas**
   - Modificar valores de células existentes.
   - Adicionar novas linhas e colunas.

5. **Estilização de Planilhas**
   - Aplicar estilos às células (cores, fontes, bordas, etc.).
   - Mesclar células.

6. **Manipulação de Fórmulas**
   - Inserir fórmulas em células.
   - Atualizar e calcular valores baseados em fórmulas.

7. **Trabalhando com Múltiplas Abas**
   - Criar, renomear e excluir abas em uma planilha.
   - Navegar entre diferentes abas.

8. **Salvando Arquivos**
   - Salvar alterações em arquivos existentes.
   - Salvar como novos arquivos.

9. **Exemplos Práticos**
   - Automação de tarefas comuns em planilhas.
   - Geração de relatórios automatizados.

## Como Utilizar os Arquivos
- Certifique-se de ter o Python instalado na sua máquina.
- Instale a biblioteca OpenPyXL utilizando o comando:
  ```bash
  pip install openpyxl
  ```
- Execute os scripts Python nesta pasta para explorar os exemplos e entender como cada funcionalidade é implementada.

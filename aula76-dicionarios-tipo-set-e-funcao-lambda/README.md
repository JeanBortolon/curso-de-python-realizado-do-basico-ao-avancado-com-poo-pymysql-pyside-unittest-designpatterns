# Documentação da Pasta: aula76-dicionarios-tipo-set-e-funcao-lambda

## Conteúdo da Pasta
Esta pasta contém diversos scripts Python que abordam os seguintes tópicos:

1. **Dicionários em Python**:
   - `aula76-dicionarios.py`: Introdução aos dicionários, suas características e usos básicos.
   - `aula76-2-manipulando-chaves-dos-dicionarios.py`: Manipulação de chaves e valores em dicionários.
   - `aula76-3-metodos-em-dicionarios.py`: Métodos úteis para trabalhar com dicionários.
   - `aula77-exercicio-dicionarios-perguntas-e-resposta.py`: Exercício prático utilizando dicionários para perguntas e respostas.

2. **Tipo Set em Python**:
   - `aula78-tipo-set.py`: Introdução ao tipo `set` e suas características.
   - `aula79-exemplo-set.py`: Exemplos práticos de uso do tipo `set`.
   - `aula80-exercicio-set-encontrando-num-duplicado.py`: Exercício prático para encontrar números duplicados usando `set`.

3. **Funções Lambda**:
   - `aula81-funcao-lambda.py`: Introdução às funções `lambda` e seus usos básicos.
   - `aula82-lambda-complexa.py`: Exemplos mais complexos de funções `lambda`.

4. **Empacotamento e Desempacotamento de Dicionários**:
   - `aula83-empacatomaneto-desempacatomento-dicts.py`: Técnicas de empacotamento e desempacotamento de dicionários.

## Objetivo
Esta pasta serve como material de estudo para compreender e praticar conceitos fundamentais de dicionários, conjuntos (`set`) e funções `lambda` em Python. Além disso, inclui exercícios práticos para reforçar o aprendizado.

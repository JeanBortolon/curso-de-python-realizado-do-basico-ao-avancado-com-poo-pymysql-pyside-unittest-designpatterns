# Documentação da Pasta: aula166-datetime-calendar-os-e-diretorios

## Conteúdo da Pasta

Esta pasta contém os seguintes arquivos Python:

1. **aula162-data-hora-em-python.py**: 
   - Explora o uso do módulo `datetime` para manipulação de datas e horas.
   - Recursos abordados:
     - Criação de objetos `datetime`.
     - Conversão de strings para datas com `strptime`.
     - Obtenção do timestamp atual com `datetime.now()`.
     - Conversão de timestamps para objetos `datetime`.

2. **aula163-calculando-datas.py**: 
   - Demonstra cálculos com datas utilizando o módulo `datetime`.

3. **aula164-formatando-datas.py**: 
   - Mostra como formatar datas e horas em diferentes formatos.

4. **aula165-exercicio-calculando-datas.py**: 
   - Exercício prático para consolidar o aprendizado sobre cálculos com datas.

5. **aula166-modulo-calendar.py**: 
   - Apresenta o módulo `calendar` para trabalhar com calendários e datas.
   - Recursos abordados:
     - Geração de calendários com `calendar`.
     - Obtenção do último dia do mês com `monthrange`.
     - Identificação de dias da semana com `weekday`.

6. **aula167-locale-traducao-no-calendar.py**: 
   - Explora o uso de `locale` para tradução de nomes de dias e meses no módulo `calendar`.

7. **aula168-modulo-os.py**: 
   - Introduz o módulo `os` para interação com o sistema operacional.
   - Recursos abordados:
     - Listagem de arquivos em diretórios com `os.listdir()`.
     - Execução de comandos do sistema com `os.system()`.

8. **aula169-os-caminhos-splitext.py**: 
   - Mostra como trabalhar com caminhos de arquivos utilizando `os.path.splitext`.

9. **aula170-os-isdir-listdir.py**: 
   - Demonstra como verificar se um caminho é um diretório e listar arquivos.

10. **aula171-os-walk-andando-nos-dirs.py**: 
    - Apresenta o uso de `os.walk` para percorrer diretórios recursivamente.

11. **aula172-os-path-getsize-e-stat.st_size.py**: 
    - Mostra como obter o tamanho de arquivos com `os.path.getsize` e `os.stat.st_size`.

12. **aula173-os-e-shutil-copia-e-cria-arquivos.py**: 
    - Demonstra como copiar e criar arquivos utilizando os módulos `os` e `shutil`.

13. **aula174-os-e-shutil-movendo-arquivos.py**: 
    - Mostra como mover arquivos e diretórios com os módulos `os` e `shutil`.

## Recursos Abordados

- Manipulação de datas e horas com `datetime`.
- Trabalhando com calendários usando o módulo `calendar`.
- Interação com o sistema operacional utilizando o módulo `os`.
- Operações com arquivos e diretórios com os módulos `os` e `shutil`.

Este README serve como referência para os conceitos e exemplos práticos abordados nesta pasta.
